# Проверка комплекта

Проверено 29 октября 2026 года в облачной среде.

- `npm ci` — установка из lock-файла прошла.
- `npm run build` — TypeScript и Vite прошли.
- `npm run build:portable` — готовый HTML создан из этих же исходников.
- 4 браузерных проверки игровых механик прошли: старт/пауза/перезапуск; поимка/100 очков/подъём и возврат белки/косточки/ускорение/машина/конец раунда; клавиатура/бег/прыжок/твёрдые препятствия; наличие мобильных кнопок.
- Отдельная проверка точного содержимого автономного HTML с выключенным интернетом прошла: WebGL, старт, изменение таймера и пауза; внешних HTTP-запросов и ошибок JavaScript не обнаружено. Снимок экрана осмотрен: лес, Люцик, белки, машина и интерфейс отображаются.

Ограничение проверки: политика облачного Chromium запрещает навигацию `file://` (`ERR_BLOCKED_BY_ADMINISTRATOR`). В тесте содержимое файла загружено в новую вкладку через `setContent`, интернет оставался выключенным. Непосредственное открытие двойным щелчком на Windows/macOS здесь не проверено. Работа локального HTML на реальном телефоне и установка APK/IPA не проверены.

Это полный комплект восстановленной первой играбельной версии, а не доказанная копия утраченного коммита e9f3533. Графика процедурная; ограничения камеры и ИИ перечислены в README. GitHub Pages не опубликован и не проверен.
