# Люцик ловит белок

Полный исходный проект восстановленной первой играбельной версии. **Это не подтверждённая копия прежнего коммита e9f3533:** в новой среде от прежнего проекта остался только `Readme`, поэтому эта версия создана заново по описанным механикам. Графика процедурная, мультяшная и упрощённая. Коммерческая полировка и фотореалистичная модель не заявляются.

## Играть без терминала — на компьютере

1. Скачайте архив `Lucia-game.zip`.
2. Щёлкните по нему правой кнопкой и выберите «Извлечь всё» (Windows) или откройте двойным щелчком (macOS).
3. В извлечённой папке откройте **ready-to-play → Lucia-play.html** через Chrome или Edge. Можно перетащить файл в окно браузера.
4. Нажмите «Играть». Ничего устанавливать, регистрировать или подключать к интернету не нужно.

Это автономный HTML-файл, а не установщик EXE, APK или IPA. Все Three.js, модели, стили и звуки встроены внутрь. Нужен современный браузер с WebGL 2 и аппаратным ускорением. Не открывайте корневой `index.html` двойным щелчком: он предназначен для Vite, а готовый автономный файл лежит в `ready-to-play`.

## Телефон

В игре есть экранные кнопки и управление камерой пальцем. На Android локальные HTML-файлы могут открываться через браузер в зависимости от файлового менеджера. На iPhone открытие HTML из «Файлов» может ограничивать JavaScript/WebGL; запуск этой локальной копии там не гарантируется. Надёжный путь для телефона — открыть опубликованный сайт в браузере. APK/IPA и подтверждённой публикации сайта в этом архиве нет.

## Что работает

- Процедурный объёмный хвойный парк, дорожки, кусты, трава, камни, лужи, поваленные стволы, лавочки, фонари и указатель.
- Люцик с кремовой гривой, тонкими ногами, коротко стриженным серо-коричневым телом, пушистыми лапами и кисточкой хвоста.
- Ходьба, бег, прыжок, поворот и радость после поимки, плавная камера сзади.
- Белки убегают от Люцика, меняют направление и постепенно ускоряются. За поимку — 100 очков. Белка безопасно забирается на дерево и спустя время возвращается.
- Косточки дают 10 очков и восстанавливаются. Золотые лакомства ускоряют на 7 секунд.
- Две оранжевые машины движутся по круговой дорожке, щётки вращаются, маячки мигают. Столкновение замедляет на 2,5 секунды. Лужи также замедляют; твёрдые препятствия блокируют движение.
- Русский интерфейс, мини-карта, очки, белки, косточки, раунд 3 минуты, старт, пауза, перезапуск и экран результата.
- Синтезированный звук двигателя и наград — включается кнопкой, по умолчанию выключен.

**Управление:** WASD/стрелки — движение, Shift — бег, Пробел — прыжок, мышь над лесом — камера, Esc — пауза. На сенсорных устройствах используются кнопки, для камеры проведите пальцем по игровому полю. При потере фокуса включается пауза.

## Разработка и пересборка

Нужен Node.js 22.12+.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173/Lucia/`.

```bash
npm run typecheck
npm run build                 # production-сборка в dist
npm run build:portable        # автономный ready-to-play/Lucia-play.html
npm run preview               # http://localhost:4173/Lucia/
npx playwright install chromium
npm test
```

Для системного Chromium: `CHROMIUM_PATH=/usr/bin/chromium npm test`. Тесты проверяют механику и открытие автономного файла с выключенным интернетом. Сначала выполните `npm run build:portable`, если изменяли исходники. ZIP не содержит `node_modules`, `dist` или `.git`; для разработки зависимости устанавливаются через `npm ci`.

## Структура

- `src/main.ts` — лесопарк, игровой цикл, камера, столкновения, ИИ, интерфейс, бонусы и звук.
- `src/models.ts` — процедурные модели персонажей, машин и косточек.
- `src/style.css`, `index.html` — интерфейс и экранные кнопки.
- `scripts/build-portable.mjs` — упаковка всех ресурсов в один автономный HTML.
- `tests/` — браузерные проверки механик и автономной версии.
- `ready-to-play/Lucia-play.html` — готовая игра, которую можно открыть без сборки.
- `vite.config.ts` — базовый путь `/Lucia/` для GitHub Pages.
- `.github/workflows/deploy.yml` — сборка, тесты и публикация `dist` при обновлении `main`.

## GitHub Pages без терминала

Публикация в этой среде не подтверждена: ранее GitHub отклонял отправку с 403.

1. Откройте `https://github.com/anelij1990-code/Lucia` → **Add file → Upload files**.
2. Из извлечённого архива загрузите содержимое папки проекта, а не сам ZIP. Для GitHub Pages достаточно файлов проекта; папка `ready-to-play` необязательна. Не загружайте `node_modules` или `dist`.
3. Убедитесь, что `package.json`, `package-lock.json`, `index.html`, `vite.config.ts`, `tsconfig.json`, `src`, `scripts`, `tests` и `playwright.config.ts` находятся в корне репозитория. Нажмите **Commit changes** в `main` или создайте PR через предложенный GitHub интерфейс.
4. Если файловый менеджер скрывает `.github`, создайте workflow вручную: **Add file → Create new file**, имя **.github/workflows/deploy.yml**, вставьте содержимое одноимённого файла из архива. Файл можно открыть обычным текстовым редактором. Сохраните через **Commit changes**.
5. Перейдите **Settings → Pages → Build and deployment → Source → GitHub Actions**.
6. Вкладка **Actions → Deploy Lucia to GitHub Pages**: дождитесь успешного `build` и `deploy`, либо запустите **Run workflow → main** после включения Pages. Если GitHub попросит одобрить среду `github-pages`, подтвердите deployment.
7. После успешного развёртывания откройте `https://anelij1990-code.github.io/Lucia/` и проверьте игру.

Для загрузки в браузере GitHub каждый файл должен быть не больше 25 МБ; файлы этого проекта меньше лимита. Если GitHub не даёт менять репозиторий даже через сайт, войдите в аккаунт с правами записи либо загрузите проект в собственный репозиторий. При другом имени репозитория измените `base` в `vite.config.ts`.

## Ограничения

Камера пока не избегает крон и препятствий. Белки используют простой ИИ, без сложного поиска пути. Стрижка и шерсть стилизованы геометрией. Публикация, установка на телефон и идентичность прежней версии не подтверждены. Внешних сервисов, сетевых запросов и платных API для самой игры не требуется.

Three.js используется по лицензии MIT; текст лицензии находится в `THIRD-PARTY-NOTICES.txt` и внутри автономного HTML.
